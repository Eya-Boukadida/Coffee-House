# ☕ Coffee House - Sousse

Site web vitrine moderne et élégant pour le café **Coffee House** situé à Sousse, Tunisie.

## 🌟 Aperçu

Coffee House propose une expérience café haut de gamme avec des cafés de spécialité, des pâtisseries artisanales et une ambiance chaleureuse.

### ✨ Fonctionnalités
- 🎨 Design moderne, épuré et responsive (Mobile / Tablette / Desktop)
- 📜 Menu interactif avec filtres et détails
- ⭐ Section avis clients
- 📍 Informations de contact, horaires et localisation à Sousse
- 🌙 Animations fluides et interface soignée

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Flexbox, Grid, animations et design responsive
- **JavaScript (ES6+)** : Interactions dynamiques et gestion du menu
- **Google Fonts** : Playfair Display & Poppins
- **Font Awesome** : Icônes

## 🚀 Utilisation

Pour visualiser le site localement :
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/Eya-Boukadida/Coffee-House.git
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur web.
